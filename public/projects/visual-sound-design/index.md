# Visual Sound Design

Um utilitário web voltado para Mestres de RPG de Mesa que desejam elevar a imersão e organização do design sonoro de uma maneira visual moderna. O que não limita apenas aos narradores de RPG, podendo ser utilizado aos para outros fins.

## ⬡ O Projeto
A ferramenta permite desenhar áreas usando a tecnologia de Canvas que emitem sons, criar paredes que bloqueiam som, e posicionar fontes sonoras espaciais. Tudo isso sincronizado em tempo real com os jogadores!

## ▪ Stack Tecnológico
- **Next.js** (App Router)
- **Konva (Canvas)** para desenho de mapas em alta performance
- **PeerJS (WebRTC)** para conexão P2P de áudio e dados em tempo real
- **Zustand** para o controle global dos estados do mapa
- **Supabase** para o banco de dados e autenticação
- **Framer Motion** para animações de interface fluidas

## ✧ Por que este projeto?
Sou aficcionado por musica e trilha sonora e como eu mesmo sou Mestre de RPG sentia falta de um aplicativo onde eu podia organizar minhas trilhas e efeitos de uma maneira visual mais completa, complexa e com funcionalidades alem das basicas e foi dai que tive a ideia de criar um canva onde posso delimitar areas onde sons são propagados e ouvidos a partir de pins. E com outras funcinalidades que vieram mais tarde ao projeto.
