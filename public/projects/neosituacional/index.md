# Administração Condominial

Uma solução completa de ponta a ponta desenvolvida para modernizar a administração de condomínios. O sistema vai muito além de um simples site institucional, atuando como um hub central para moradores, administradores e síndicos.

## ✦ Tecnologias Utilizadas
- **React + Vite** para um frontend ultra-rápido (SPA).
- **Supabase** como backend as a service, cuidando da autenticação segura e banco de dados em tempo real.
- **Radix UI & Tailwind** para componentes acessíveis, modulares e um design system limpo.
- **BlockNote** para o editor de texto rico (WYSIWYG) do CMS interno.
- **Recharts** para a visualização de dados financeiros no painel do síndico.

## ◎ O Desafio
A administração de condomínios geralmente sofre com a falta de transparência e sistemas arcaicos que não se comunicam entre si. O desafio era criar uma plataforma onde o site público (marketing) fosse perfeitamente integrado ao sistema de gestão interno.

## ✧ A Solução
Desenvolvemos uma aplicação dividida em três pilares:
1. **Site Institucional & Blog:** Uma vitrine pública para a administradora atrair novos condomínios, com um blog otimizado onde os próprios funcionários podem publicar artigos usando um editor de texto estilo Notion (BlockNote).
2. **Dashboard do Administrador:** Um painel onde a equipe gerencia chamados, comunicados e atualiza o conteúdo do site sem precisar mexer em código.
3. **Portal do Síndico:** Acesso exclusivo para os síndicos visualizarem métricas através de gráficos interativos (Recharts) e gerirem as demandas de seus respectivos condomínios.

## ◈ Destaque Técnico
A implementação de um CMS customizado com o BlockNote integrado diretamente ao Supabase permitiu que o cliente tivesse controle total sobre o conteúdo do seu site sem depender de plataformas de terceiros pesadas como o WordPress.
